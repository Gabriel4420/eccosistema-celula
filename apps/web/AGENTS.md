# Instruções do painel web

Estas regras complementam o AGENTS.md da raiz.

- Usar Next.js App Router.
- Componentes de interface não acessam Prisma.
- Utilizar Server Components por padrão.
- Utilizar Client Components apenas quando necessário.
- Formulários devem usar Zod.
- Não duplicar regras de negócio da API.
- Garantir navegação por teclado e estados de carregamento.
